# LAST SONG!

공연은 절대 멈추면 안 된다. 무대 위에서 터지는 사고를 뛰어다니며 해결하는 1~2인 픽셀 협동 프로토타입.

> 음악에 맞춰 버튼을 누르는 게임이 아니라, **음악이 끊기지 않도록 무대를 지키는 게임**.

이 저장소의 헌법은 `ART_GUIDE.md` 다. 스프라이트는 `tools/gen_sprites.py` 에서만 만든다.

## 실행

브라우저에서 ES module을 쓰므로 로컬 서버가 필요하다.

```powershell
python -m http.server 8080
```

그리고 http://localhost:8080 를 연다.

## v0 범위

학교 축제 한 곡, 한 무대, 두 스태프, 사고 네 종류.

1. 기타 케이블 빠짐 → 케이블을 앰프에 꽂기
2. 기타 줄 끊어짐 → 백스테이지 예비 기타를 가져가 E 홀드
3. 드럼 스틱 날아감 → 떨어진 스틱을 드러머에게
4. 마이크 피드백 → 마이크를 앰프에서 멀리 옮기기

3분 버티기. 관객 텐션이 0이면 실패.

빠진 케이블을 물건 든 채로 밟으면 넘어진다.
